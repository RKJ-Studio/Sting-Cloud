# ⚡ StingCloud — All-in-One Cloud & Digital Solutions

StingCloud is a modern, customer-focused web platform delivering end-to-end digital services:
- 🚀 **Web Development** (Fast, responsive, high-converting websites)
- 🛡️ **Premium Hosting** (99.99% Uptime SLA, Global CDN, SSL)
- ⚡ **VPS Cloud Servers** (Dedicated NVMe SSD & full root access + Interactive 3D Server Explorer)
- 🤖 **Bot Development & Hosting** (24/7 Always-online Discord & AI bots)
- 💻 **Custom Software Development** (Full-stack web & mobile apps)
- 📈 **SEO & Digital Growth** (Core Web Vitals & Google ranking optimization)

---

## 🛠️ Tech Stack
- **HTML5**: Semantic, accessible markup with ES Module Import Maps
- **CSS3**: Vanilla CSS with modern custom design system, glassmorphism, responsive grid & flexbox
- **JavaScript (ES6+)**: Custom particle background, typing animations, scroll spy, interactive 3D showcase, and AJAX form integration
- **Three.js (v0.170.0)**: Interactive 3D 3U Rack Server inspection experience (`vps.html`)
- **Formspree**: Connected backend endpoint for client inquiries

## 🚀 Getting Started

Simply clone the repository and serve the folder with any static web server:

```bash
git clone https://github.com/JayeshPatil2009/StingCloud.git
cd StingCloud
```

Serve with any static web server (or VS Code Live Server):
```bash
# Using Python
python -m http.server 3000

# Or using Node.js serve
npx serve .
```

*(Optional)* If you want to bundle `vps-app.js` into a standalone `vps-bundle.js` for offline `file://` usage:
```bash
npm install
npm run build
```
